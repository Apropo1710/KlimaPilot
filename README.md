# KlimaPilot

Native Android-App zur direkten lokalen Steuerung und Überwachung von Mitsubishi-Heavy-Klimaanlagen über das WF-RAC-WLAN-Modul. Eine optionale ioBroker-WebSocket-Verbindung dient der Synchronisierung von Klimaprofilen; sie ist nicht der direkte Steuerungsweg der Klimaanlage.
